Exam Pattern

Computer-Based Test (CBT/online), two tiers — Tier I (screening) and Tier II (main, includes a Skill/Typing Test component). · Tier I: 60 minutes. Tier II: conducted in two sessions on the same day (objective sections in one session, Skill/Typing Test in the other).
Tier I (single paper, 4 sections)100 questions, 200 marks total — English Language, General Intelligence, Quantitative Aptitude, General Awareness, 25 questions/50 marks each
Tier II Section 1: Module I Mathematical Abilities + Module II Reasoning & General Intelligencepart of 135 questions/405 marks total (3 marks per question); -1 per wrong answer
Tier II Section 2: Module I English Language & Comprehension + Module II General Awarenesspart of the same 135Q/405 marks; -1 per wrong answer
Tier II Section 3: Module I Computer Knowledge Test + Module II Skill Test/Typing TestComputer Knowledge is objective with -1 per wrong answer; Skill/Typing Test is qualifying only, no negative marking
Negative MarkingTier I: -0.50 per wrong answer. Tier II: -1 mark per wrong answer across Sections 1, 2, and the Computer Knowledge module of Section 3. No negative marking on the Skill Test/Typing Test (qualifying, not scored competitively).
Passing MarksN/A — merit-based/normalized ranking, no fixed qualifying %. (Category-wise minimum qualifying scores are set separately each recruitment cycle for shortlisting, not a fixed universal percentage; Skill/Typing Test has its own pass/fail speed standard which is qualifying, not a "marks" cutoff.)

Secondary-sourced from multiple coaching-site aggregators, which agree closely on both tiers' structure for the 2026 cycle; official SSC CHSL notification PDF not directly fetched (ssc.gov.in access unreliable for automated fetch). Fee figure cross-confirmed by 3 sources.

Career Progression

Not an official timeline — a commonly cited estimate.

  • LDC / JSA → Upper Division Clerk (UDC) / Senior Secretariat Assistant — around 5–7 years (by seniority, sometimes a departmental exam)

Frequently Asked Questions

What's the difference between Tier I and Tier II negative marking?

Tier I deducts 0.50 marks per wrong answer; Tier II (objective sections) deducts a full 1 mark per wrong answer, so guessing is riskier at the Tier II stage.

Do I have to clear the typing/skill test separately even if I score well in the objective sections?

Yes — the Skill Test (for Data Entry Operator posts) or Typing Test (for LDC/JSA posts) is a mandatory, separate qualifying hurdle; it doesn't add marks but you must meet the speed standard to remain in contention.

Which posts does SSC CHSL recruit for, and does the exam differ by post?

CHSL recruits for Lower Divisional Clerk/Junior Secretariat Assistant, Data Entry Operator, and Postal Assistant/Sorting Assistant among others — the written exam (Tier I & II) is common to all posts; only the Skill Test vs Typing Test requirement differs by the post you're being considered for.

Is there a fee difference between General and OBC candidates?

No — General, OBC, and EWS candidates all pay the same Rs 100; only SC, ST, PwBD, Ex-Servicemen, and all women candidates are exempted.
